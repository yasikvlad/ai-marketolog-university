# Synthesis: Структура программы Потока 3

_Last updated: 2026-06-03 — based on src-20260603-potok2-lesson-transcripts (13 транскриптов), src-seed-program-structure, ТЗ уроков_

## Current understanding

Структура Потока 3 проектируется **обратным дизайном** (от точки Б в деньгах) на базе
реальных транскриптов Потока 2. Главный сдвиг против черновика — **порядок модулей выверен
по фактическому ходу уроков и педагогическому принципу Влада** «сначала руками → потом
автоматизация → потом агенты».

### Метапромт-методология (многоразовый инструмент проектирования)

Программа строится по 8 принципам:
1. **Результат в деньгах** — точка Б = измеримый результат (запуск/продажи/продукт).
2. **Один урок = один ЦКР** — осязаемый артефакт на руки, не «узнал про».
3. **Модуль = одна способность** — ЦКР модуля = «что ты теперь умеешь сам».
4. **Граф зависимостей** — урок опирается только на пройденное, без ссылок вперёд.
5. **Язык аудитории** — запрещены: онбординг, инфраструктура, стек, деприсёрч, упаковка,
   фреймворк, пайплайн. Тест: поймёт ли новичок без расшифровки.
6. **Быстрая победа в начале** — дофаминовый якорь как можно раньше.
7. **Делегирование, не зубрёжка** — где можно, задачу делает AI-сотрудник.
8. **Упаковка в пакеты** по глубине контента: база → +контент-машина → премиум.

### Решённые развилки

**Развилка 1 — Цифровые сотрудники: ПОСЛЕ Deep Research** (исправлено vs первый черновик
«до»). Основание из первоисточника: реальный порядок Потока 2 = Настройка → Deep Research →
Цифровые сотрудники → Упаковка; прямой принцип Влада «сначала ручками провести research,
потом автоматизировать в скиллы»; Deep Research = фундамент-хаб для данных. Зависимость
«до упаковки знать сотрудников» выполнена (сотрудники перед упаковкой).

**Развилка 2 — название «Упаковка продукта» → «Твой клиент и твоё предложение»**
(подзаголовок: AI-маркетинг-стратегия — кому продаём и от чего невозможно отказаться).
Урок = ДНК клиента + Лестница Ханта + Оффер Хормози.

### Структура модулей (нормальный язык)

**ПАКЕТ 1 — База «Запуск с нуля»**
- М0 · С чего начинаем — настроил инструменты, первая победа. *(закрыть затыки: Git/permissions/Vercel/установка скиллов)*
- М1 · Управляем нейросетями — метапромтинг, транскрибация, перенос памяти. ЦКР: уверенно командуешь AI.
- М2 · Изучаем рынок (Deep Research) — мультивселенная → решение «1 ЦА + 1 боль + 1 продукт». ЦКР: утверждённая гипотеза.

- М11 · AI-воронки (Даня Фролов, гость) — *необязательный*. ЦКР: воронка лид-магнит → бот → заявка.

**ПАКЕТ 3 — Премиум ($1500)**

# Synthesis: Methodology & Content Assets

_Last updated: 2026-05-12 — based on 3 seed sources, 2 claims, 6 notes_

## Current understanding

Главный IP-актив AI-Маркетолога — **7 авторских методологий Влада**: 1) ДНК Бизнеса; 2) ДНК Клиента; 3) Мультивселенная Deep Research; 4) Оффер по Хормози; 5) Вайб-кодинг; 6) Обратный инженеринг; 7) Формула «Кнопка Бабло» (1 Аудитория + 1 Боль + 1 Продукт). Каждая — **отделимая структура**, применимая независимо. Это **то, что нельзя скопировать**, прочитав лендинг конкурента.

**Стек инструментов** курса — 63 нейронки, но **узкий выбор для исполнения**: Claude Code (Opus 4.7 / Sonnet 4.6) — единственный инструмент для вайб-кодинга. Остальное — Perplexity / ChatGPT / Gemini / Grok для Deep Research, NotebookLM как «точка сборки», ElevenLabs / HeyGen для медиа. Эта **сегрегация широты исследования и узости исполнения** — стратегическое решение (см. c-0006). На уроке 8 продемонстрирован вайб-кодинг 193 строк кода **за 31 секунду**.

**Философия методологии**: «Не обучить маркетингу, а дать инструменты, которые делают маркетинг за тебя». Это переопределяет образовательный продукт: **скорость > понимание**. KPI — деньги во время курса, не сертификат после (см. c-0005).

**Кейсы как контент-актив**: София Дробинина (10 часов контента → AI-ассистент → CRM-приложение за курс) — флагман-кейс, доказывающий методологию обратного инженеринга. Используется в продающих материалах. Другие кейсы: Катерина Дегтярь (SaaS звонков), Виктория Кова (HR), Стас Шевчук (девелопмент Бали). Каждая стратсессия — это **отдельный контент-актив**, конвертируемый в рилс/кейс/продающий материал.

**Содержательная траектория курса:**
> Инструменты → Мышление → Ассистенты → Исследования → Маркетинг → Лендинги → Агенты → Код

Это **8 воркшопов Потока 1** + Q&A после каждого. Старт с базовой настройки (Z2U, подписки) → переход к мышлению (промт-инжиниринг) → к продуктовым артефактам (ассистенты, лендинги, агенты, код). Финал — деплой собственного Instagram-бота на Railway.

## Open questions

- Каждая из 7 методологий должна быть **отдельной публикуемой статьёй** на лендинге / в блоге? Это IP-актив, не «лекция».

## Strategy implications (что делаем прямо сейчас)

1. **Каждая из 7 методологий** = отдельная страница на лендинге / отдельный лид-магнит. Это IP-актив.
2. **Кейсы стратсессий** Потока 1 — публиковать в формате рилс + длинный пост (отдельно). Один кейс — несколько форматов.
3. **Стек инструментов** показывается на лендинге блоком «63 нейронки» (масштаб) + узкая ставка «Claude Code как ядро» (отстройка).
4. **Не размывать ядро Claude Code** на «Cursor + Lovable». Это часть отстройки от Анжелы.
5. **27 AI-сотрудников** — отдельный страничный продукт (employees.html уже есть). Каждый — потенциальный stand-alone продукт.

# Claude Code как единственный инструмент для вайб-кодинга — стратегическое решение

## Context

В индустрии AI-курсов норма — «обзор всех инструментов»: Cursor + Bolt + Lovable + Claude + GitHub Copilot. AI-Маркетолог явно отходит от этой нормы.

## Evidence walk-through

- `n-vibe-coding-claude-only`: явное заявление позиции из воркшопа.
- `n-methodology-7-vlad`: вайб-кодинг — одна из 7 авторских методологий, привязана к Claude Code.
- `n-competitor-anjela`: Анжела работает с 1 платформой (ChatGPT), мы — с 30+ нейронками. Но в коде — узко на одну. Это **сознательная сегрегация**: широта стека для исследования, узость для исполнения.

## Counter-evidence / edge cases

- Если Anthropic поднимет цены или ухудшит модель — стек уязвим. Нужен fallback план.
- Часть учеников может уже иметь Cursor подписку. Конфликт: их «переучивать» или дать опционально использовать?

## Implication for project (подробнее)

1. **На лендинге** — обязательно указывать Claude Code как ядро стека. Это часть отстройки.
2. **В программе** — Урок 6 (создание лендингов) и Урок 8 (вайб-кодинг) построены ТОЛЬКО на Claude Code.
3. **При выборе обновлений курса** — следить за Anthropic roadmap (новые версии Opus/Sonnet), быстро встраивать.
4. **Для маркетологов-преемников:** не дробить позицию. Если кто-то скажет «давайте добавим Cursor» — это разбавит отстройку. Cursor можно упоминать как факт рынка, не как часть программы.
5. **Партнёрство с Anthropic** — возможный апсайд (Cowork, новые фичи в первую очередь). Стоит развивать.

# ToV Влада — рабочий инструмент ТОЛЬКО для аудитории AI-Маркетолога

## Context

AI-Маркетолог — ниша маркетологов/предпринимателей/новаторов. Эта аудитория ценит прямолинейность, сленг, антиперфекционизм. ToV Влада точно попадает в их язык. Но **в смежных проектах** (struchaev-yasko, например) тот же ToV конвертирует существенно хуже.

## Evidence walk-through

- `n-tov-svoy-pacan`: архетип «свой пацан» работает в ниша-зависимо.
- `n-tov-markers-vlad`: лексикон («движ/машина/завод») — узнаваемый для целевой аудитории маркетологов.
- `n-3-segments-ca`: все три сегмента AI-Маркетолога культурно совместимы с «своим пацаном» — общая культура предпринимательских Telegram-чатов и YouTube.
- Кросс-референс: в проекте struchaev-yasko (psy-аудитория) тот же ToV — анти-паттерн (см. там claim c-0007).

## Counter-evidence / edge cases

- Часть аудитории «новаторы» — более технические, могут реагировать слабее на сленг. Но в основном тоже из той же культурной воды.
- B2B-сегмент (если будет в будущих потоках) — потребует адаптации.

## Implication for project (подробнее)

1. **Маркетологам-преемникам:** при работе с AI-Маркетологом — **сохранять ToV Влада дословно**. Маркеры обязательны.
2. **При создании контента от имени Влада** для других проектов — **проверять аудиторию**. Если psy/B2B/академики — переписывать под их язык.
3. **AI-скилл Sofia** для продаж в переписках обучен на голосе Влада — работает в нише AI-Маркетолога. Перенос на другие проекты — без адаптации не работает.
4. **Контент-машина** (16 форматов из 1 голосового) — конвертирует голос Влада в текст с сохранением маркеров. Адаптации под другие аудитории — отдельная работа.

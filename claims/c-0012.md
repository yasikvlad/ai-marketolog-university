# Кейсы Потока 1 — главное доказательство методологии, должны быть на лендинге

## Context

c-0005 (KPI = деньги во время курса) — декларативный claim о философии курса. Без публичных доказательств он не работает как продающий аргумент. На лендинге Потока 2 этот claim **требует материального подтверждения** — реальных кейсов с цифрами.

## Evidence walk-through

- `n-graduation-cases-real-results`: 8 публичных кейсов с финальной встречи 2026-04-07. Каждый ученик представил себя в эфире, результаты не «маркетинговые подгонки», а живая презентация.
- `n-result-money-during-course`: декларация KPI (доход во время курса), которую кейсы прямо подтверждают.
- `n-philosophy-ai-optimization-innovation`: философский фундамент — кейсы являются и оптимизацией (Владимир Репко: $2K/мес экономии), и инновацией (Юра Довгань: 4 дня от идеи до мероприятия).
- `n-vlad-son-14-yo-300-case`: дополнительный «непрофессиональный» кейс снимает страх «AI сложно».

## Counter-evidence / edge cases

- Не все 8 кейсов одинаково сильны. Например, «Анастасия Мельник — диплом с отличием» — более слабый кейс для маркетинга, чем «Андрей Полозовский — $5K/месяц». Нужно отбирать топ-5 для лендинга.
- Кейсы из 4-2026, лендинг живёт 6-2026 → могут устаревать. Нужно периодически обновлять (например, как сейчас обстоят дела у Андрея Полозовского спустя 3 месяца).
- Аудитория Потока 2 может скептически относиться к «AI-успехам» — кейсы должны быть **гранулярными** (что конкретно сделано, как, какой инструмент).

## Implication for project (подробнее)

1. **На лендинге Потока 2 обязательно** добавить раздел «Кейсы Потока 1» (если его ещё нет).
2. **Структура каждого кейса**: фото/имя → ниша → стартовая точка → результат во время курса → метод (методология/инструмент Влада) → цифра.
3. **Топ-5 кейсов** для primary slot: Полозовский, Репко, Кова, Drobinina, Drigola.
4. **Дополнительные** (для скролла): Хавро, Довгань, Мельник.
5. **Для рилсов прогрева**: один рилс = один кейс, формат «До курса AI-Маркетолог → После». R-серия с n-graduation-cases-real-results.
6. **Для email-сериала** Потока 3: каждое письмо = один кейс + методология.
7. **Видео-контент**: возможно записать **отдельные интервью** с каждым выпускником (5-10 мин) — это IP-актив на годы.
8. **Маркетологам-преемникам**: НЕ изобретать кейсы. Использовать готовые 8 + добавлять новые с каждым потоком.

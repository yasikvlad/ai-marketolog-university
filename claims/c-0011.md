# AI-Маркетолог Потока 2 использует ДВУХКАНАЛЬНУЮ воронку

## Context

В Потоке 1 у AI-Маркетолога был один основной канал — лендинг + WayForPay. В Потоке 2 канал раздвоился: для холодных лидов — лендинг (https://new.aimarketolog.site/), для тёплых — Telegram-сообщения с переходом в bot @yasko_robot.

## Evidence walk-through

- `n-payment-channel-yasko-robot`: Telegram bot @yasko_robot — основной канал для тёплых аудиторий, отличие от WayForPay-кнопок на лендинге.
- `n-two-funnels-cold-vs-warm`: детальное сравнение двух каналов по 10 параметрам — структура программы, набор пакетов, наличие urgency-механик и т.д.

## Counter-evidence / edge cases

- Если технически оба канала тянут в одну CRM/бухгалтерию — это **не отдельные каналы**, а **разные UI к одному pipeline**. Нужно подтвердить с командой.
- Возможна ситуация, когда «холодный» пользователь, наткнувшийся на TG-пост, конвертит в TG-bot, но это OK — он перешёл в тёплый канал.

## Implication for project (подробнее)

1. **Маркетологам-преемникам**: **не унифицировать каналы**. Каждый бьёт в свой сегмент.
2. **Лендинг** (холодный канал):
   - Сохранять все 4 urgency-механики (c-0009)
   - Сохранять value-stack $4200 (n-bonuses-stack-4200)
   - Сохранять калькулятор потерь
   - Сохранять личную историю Влада
   - Сохранять FAQ
3. **Telegram-канал**:
   - НЕ копировать туда весь продающий контент с лендинга — это не нужно тёплой аудитории
   - Использовать @yasko_robot для оплаты
   - Краткие посты + рассрочки + контакты + быстрый buy-flow
4. **Раздельная аналитика**:
   - UTM-маркировка каждого канала
   - Отдельный учёт CR по каналу
   - Hypothesis: warm CR значительно выше cold CR
5. **Двойная инфраструктура — нагрузка на операционку**:
   - WayForPay для холодного — настроенный pipeline
   - @yasko_robot для тёплого — отдельная инфраструктура, требует поддержки
   - Возможен **Single Point of Failure** в каждом — иметь backup-flow (например, прямой PayPal/USDT при сбое)
6. **Для Потока 3**: возможно добавить **третий канал** — email-цепочка с собственным lead-magnet pdf и embedded buy button. Это покроет «холодный → тёплый» переход.

# AI-скилл Sofia — критичный кусок воронки, деградация = провал монетизации

## Context

Воронка AI-Маркетолога заканчивается **продажей в личке через голосовые** (механика c-0004). Sofia — оцифрованная версия этой механики (ToV Влада + продуктовый оффер + скрипты + ElevenLabs).

## Evidence walk-through

- `n-tov-sales-mechanics-30min`: 30 минут от первого касания до согласия — конкурентное преимущество, которое теряется при ручном масштабе.
- ~50 необработанных лидов сейчас (из memory team) — это **потерянная выручка**. При среднем чеке $500 = $25K.
- Sofia пока в работе, не в проде. Это **bottleneck воронки**.

## Counter-evidence / edge cases

- Голосовые от AI могут восприниматься «неискренне» — нужно тестировать на ограниченной аудитории сначала.
- Sergey (продажник) может закрыть часть лидов вручную — но не масштаб.

## Implication for project (подробнее)

1. **Sofia — приоритет №1 операционки** Потока 2. Без неё запуск Потока 3 нельзя.
2. **Метрика lead-time** в Telegram — публичная для команды. Target: < 5 минут.
3. **A/B тест**: Sofia (AI-голосовые) vs Sergey (человек) на сегменте аудитории. Метрика — конверсия + NPS.
4. **Запасной план**: если Sofia не работает с голосовыми (звучит «как робот») — текстовая версия в стиле Влада. Текст менее эффективен, но лучше необработанных лидов.
5. **Для маркетологов-преемников:** Sofia — это IP-актив Влада, не отчуждается. Но методология обратного инженеринга для создания **аналога Sofia** в другом проекте — отчуждаемая.

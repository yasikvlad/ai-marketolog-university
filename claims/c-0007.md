# Бесплатный live-веб — стратегическое конкурентное преимущество, не источник дохода

## Context

Анжела Петкова берёт $150 за 3-часовой воркшоп — это её основная точка входа. AI-Маркетолог делает live-веб бесплатным — больше барьер на входе vs больше масса аудитории.

## Evidence walk-through

- `n-competitor-anjela`: явное сравнение «бесплатный веб vs $150».
- `n-positioning-anti-infocyganstvo`: формат «показываю в действии» — требует **массовости** для масштабирования влияния. Платный веб сокращает охват.
- Confidence M, потому что: нет прямого эксперимента «платный vs бесплатный веб» в наших данных.

## Counter-evidence / edge cases

- Часть аудитории воспринимает «бесплатное = низкокачественное». Платный веб может быть сигналом качества.
- При очень дорогом продукте ($3500+) — платный веб может действовать как самоквалификация. Но при $500–800 — не нужен.

## Implication for project (подробнее)

1. **Не вводить плату за веб** в Потоке 2 и 3. Веб остаётся бесплатным.
2. **Регистрационная воронка** через бот — обязательная фильтрация (контакт + согласие на коммуникацию). Это работает как «мягкая плата» вниманием.
3. **Запись веба** — давать после регистрации, не публично в YouTube. Это сохраняет ценность веба.
4. **Если в будущем понадобится премиум-формат** — делать его рядом (например, $50 за «расширенный мастер-класс с Q&A»), но **основной веб остаётся бесплатным**.
5. **Для маркетологов-преемников:** аргументы про «давайте монетизировать веб» — отклонять. Веб — это long-term инвестиция в воронку, не sale-event.

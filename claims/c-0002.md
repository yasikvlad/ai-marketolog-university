# Пакет «Под ключ $3500» — необходимый якорь сверху ценовой сетки

## Context

Маркетологам-преемникам легко возникает идея «убрать дорогой пакет, который не продаётся, чтобы не пугать». Это ошибка: дорогой пакет нужен **не для продажи**, а для **смещения восприятия** дешёвых.

## Evidence walk-through

- `n-pricing-tiers-and-anchor`: $3500 явно описан как якорь сверху. $800 кажется «дёшево» на его фоне.
- Дополнительный якорь — «бюджет запуска бренда $10 000» (внешний рыночный) — делает $800 экономией 10×.
- `n-test-format-low-price`: «программа тестовая → цены минимальные» работает в комбинации с якорем.

## Counter-evidence / edge cases

- Если конверсия в $3500 окажется нулевой долго — можно заменить на «$3500: спросить о персональной программе» (без активного оффера, но визуально якорь сохраняется).
- В отдельных рекламных креативах якорь можно скрывать (для холодной аудитории) — но на лендинге он обязателен.

## Implication for project (подробнее)

1. **Pricing-блок** на лендинге обязательно показывает все 4 пакета: $250 / $500 / $800 / $3500.
2. Кнопка $3500 — «Обсудить детали», не «Купить» (снижает страх и делает осмысленным).
3. Внешний якорь «бюджет $10K» — в продающих материалах, в разделе сравнения.
4. **Если в Поток 3 появится пакет $7000** — $3500 переезжает в «середину», но новый якорь сверху нужен обязательно.
5. **Не использовать скидку как основной механизм продаж** — она работает разово (ЧП, день рождения), системно не используется (см. кастдев Стручаева — там это срабатывает только 17%).

# Воронка вебинара = 7 этапов, каждый продаёт следующий — это linear progression

## Context

Часто маркетологи строят воронку как «лид-магнит → пугающий веб → купи». Воронка AI-Маркетолога устроена иначе — каждое сообщение **продаёт ТОЛЬКО следующий шаг**, не финальный продукт.

## Evidence walk-through

- `n-funnel-7-stages-webinar`: 7 явно поэтапных шагов, каждый — отдельный мини-call-to-action.
- `n-funnel-3-levels-delegation`: лестница навыков даёт логическую структуру progression.
- `n-positioning-anti-infocyganstvo`: формат «показываю в действии» работает только если человек дошёл до live-веба.

## Counter-evidence / edge cases

- Часть аудитории «горячая» — готова купить уже на этапе 2 (после видео). Воронка должна не мешать им (кнопка «Купить» доступна везде), но не быть на этом построена.
- Чем длиннее воронка, тем выше требования к каждому касанию — холодные дропают.

## Implication for project (подробнее)

1. **Каждое сообщение бота / каждый рилс прогрева** — должен явно отправлять на следующий этап, не на финальную страницу оплаты.
2. **Этап 5 (приход на live-веб)** — критичная точка. Здесь крюк «бесплатный AI-сотрудник тем, кто в онлайне».
3. **Метрика для каждого этапа** — % перехода к следующему. Аналитика на каждый дроп.
4. **Этап 4 (показ команды AI-сотрудников)** — визуальный, нужны качественные карточки/видео. Без визуала этап слабый.
5. **Этап 7 (масштаб 7 навыков + FOMO)** — финальный pitch, ставка на FOMO для нерешивших.

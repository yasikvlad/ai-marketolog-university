# Влад · Запуск на $120 000 с AI-pipeline

## Точка А (до)

До перехода на AI — обычный продюсер с командой 5-7 человек. Запуски шли через классический стек: маркетолог + дизайнер + копирайтер + таргетолог + продавец. Бюджет на запуск — **$10 000+**, время — **2-3 месяца**.

## Что сделал

- Применил **полный 8-этапный AI-пайплайн** (см. n-pipeline-8-stages-canonical):
  Research → Упаковка → AI-сотрудники → Сайты → Квизы → Vibe-coding → Контент-завод → AI-таргет
- Заменил большую часть команды на AI-агентов
- Параллельно использовал свой AI-агент продаж (case-vlad-ai-agent-1500)

## Точка Б (результат)

**$120 000** на запуске с AI. Это **главное numeric proof** на лендинге и в продающих материалах. Влад регулярно использует эту цифру как доказательство масштаба возможностей AI-подхода.

## Где используем

- **Лендинг:** блок «Proof» — большая цифра рядом с историей Влада
- **Hero Section:** в подзаголовке как одна из 3-х opening цифр
- **Рилсы:** R-кейс «$120K запуск через AI — без отдела маркетинга»
- **Воронка:** прогрев для предпринимателей + маркетологов (вилка чека от $1K и выше)
- **Sales-скрипт:** на возражение «такие масштабы — только для гуру»
- **Конференц-преза:** упоминается на слайде кейсов (см. src-20260518-conference-deck)

## Философия

- **2 ключевых действия = деньги:**
  1. Говорю → Сторис / Reels / Telegram
  2. Продаю → В личке (переписка, лиды)
- Всё остальное = масштабирование вокруг этих двух
- **Аудитория = личный актив Влада за 15 лет** — % с продаж тёплой аудитории не платится
- **% делится только с новых направлений**, созданных совместно

## 3 блокирующие проблемы и решения

| Проблема | Решение |
|---|---|
| Нет системы ведения Instagram | Менеджмент контента (Данил → Света) |
| Тяжело идут продажи в личке | AI-скилл **Sofia** + Сергей обрабатывает лиды |
| Нет конвертера (лендинг + VSL) | **Ключевой приоритет Влада** |

## AI-скилл Sofia

- AI-ассистент для переписки в продажах: тон голоса, продуктовый оффер, скрипты
- **~50 необработанных лидов** на момент протокола
- Возможны голосовые через ElevenLabs

## Партнёрская программа

- 20% комиссия (но не объявлено ученикам)
- Ученики уже органически рекомендуют курс
- Данил берёт на себя

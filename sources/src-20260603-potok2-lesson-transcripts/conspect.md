## Что внутри каждого урока (выжимка)

### ВШ №1 — База: экосистема Claude
- Claude как «ламбо»: chat / coworker / code. Установка (Git, Homebrew, папка, permissions Accept→Bypass).
- Выбор модели: Sonnet — простое; Opus + high effort + 1M — дорогие задачи («мраморная говядина»).
- Метапромтинг: ИИ пишет промт для ИИ. Контекст — король, но не указывать «как делать».
- Транскрибация (Whisper Flow, YouTube Ultra), перенос памяти между чатами (хаос как норма → один блокнот).

### ВШ №2 — Deep Research (фундамент)
- ДНК Бизнеса (контекст о себе) → метапромтинг → «мультивселенная»: 3 промта (рынок / ЦА / конкуренты) × 3-5 нейронок (Perplexity, ChatGPT, Gemini, Parallel AI) параллельно.
- NotebookLM = «точка сборки» / объективизатор (синтез второго уровня). Каждая нейронка — «мнение подруги».
- ЦКП этапа = **принятое решение**, не материалы: 1 ЦА + 1 боль + 1 продукт + 1 оффер. «Перестаньте думать — принимайте решения».
- Deep Research = big data / хаб проекта, к которому потом обращаются нейронки-сотрудники.
- Микросегментация: 4 ЦА × 4 боли = 16 офферов/сайтов/воронок (как Влад крутит $30-40k бюджета).

### ВШ №3 — Цифровые сотрудники (SKILLS) — ключевой
- **Иерархия сущностей**: Claude Project (ассистент) → **Skill** → **MCP-коннектор** (Zoom/Gmail/Calendar/GitHub/Telegram) → **Plugin** (несколько скиллов + коннекторов + «надзиратель») → **Agent** (автономный, на сервере, по routines) — *Agent = бонус/премиум, не база*.
- Как создаётся скилл: организовать всю инфу по задаче → скармливать Claude поэтапно → «доведи до результата, сделай сотрудника» → **«упакуй в скилл»**. Инструмент — `skill-creator` («детородный орган»). Скилл сам себя тестит/дорабатывает → папка SKILL.md + триггеры + workflow + ассеты.
- Хранение: локально (∞, в Desktop) или облако (~30-100, в chat/code). Лучше использовать в **code**.
- Самый ценный сотрудник — **AI-продавец** (знает продукт + эксперта + технику продаж + ToV; работает на сервере ~$5/день).
- **Routines** — расписание на облаке Claude (работает при выключенном компе).
- Признание Влада: на прошлом уроке выкатил базу сотрудников БЕЗ обучения установке — ученики «плакались». Этот урок исправил ошибку. → **в Потоке 3 установку давать сразу.**

### ВШ №4 — Упаковка (клиент + предложение)
- ИИ-ассистент «ДНК Клиента» (6 файлов методологии): основы ЦА, сегментация, портреты, боли/триггеры, язык, руководство.
- Три пути данных: A) CustDev (анкеты/интервью), B) Deep Research (синтетические), C) Telegram-выгрузка.
- Лестница Ханта → Оффер по Хормози (Результат×Вероятность / Время×Усилия) → агрессивный → адаптация под стиль Влада → HTML-прототип → кросс-чек данными.
- Проверка оффера: шкалы «Понятно?» и «Хочу?» (1-10). Рефрейминг продукта в услугу/промежуточный шаг.

### ВШ №5 — Vibe-coding лендингов
- Claude Code → лендинг из промта → Vercel (частый затык: 403/токены → универсальная инструкция связки через MCP/Chrome).
- GitHub = «Google-диск для гиков». Интерактив: калькуляторы, квизы, лид-магниты, встроенные боты.
- Дизайн-стек (анонс будущих модулей): SEO-пак (9 скиллов навигатора), quiz-funnel, Higgsfield MCP (Nano Banana + Seedance), 21st.dev, UI/UX Pro Max, Superdesign, Supabase (БД/заявки).
- Stop-scroll / canvas-анимация = тренд дорогих сайтов ($9-15k у фрилансеров → скилл-скрипт).
- Антиперфекционизм: лендинг по боту на Superdesign → $80k с холодного.

### ВШ №6 — Контент-смыслы
- Лестница Ханта (6 уровней осознанности) → прогрев (4 ползунка) → форматы под каждый уровень.
- Плагин Content System (надзиратель → карусели/reels/посты) + Direct Funnel skill (лид-магниты, кодовые слова, CTA).
- ToV-скилл + humanizer-ru (убрать «видно что AI»). VSL (15-блочная структура).

### Визуал (Женя Янченко)
- Принцип: AI **оживляет** фото (не генерит с нуля). Пайплайн: идея → раскадровка → опорные кадры → анимация → склейка.
- 4 уровня инструментов. Цифровой аватар (оцифровка лица), Higgsfield Soul/Cast, Kling/Seedance.
- *Примечание: в Потоке 2 «аватар» жил здесь. Отдельный урок HeyGen+ElevenLabs — план Потока 3.*

### Карусели (Света)
- Скилл editorial-carousel + конфигуратор: 9 тем, шрифты, фото/видео-фоны → рендер PNG.
- ЦКР: карусель + **личный скилл «Карусель by [имя]»** со своим дизайном.

## Q&A-сессии (между уроками) — что вызывало вопросы

- **Q&A №1** — workflow на примере Ромы: разбить задачу на пазлы, NotebookLM (источники→чат→сущности), базовая настройка Claude, уход от PDF к интерактивному сайту.
- **Q&A №2** — Deep Research: качество = качество входа; стек 3 нейронки → NotebookLM; ЦКП = решение; big data проекта; микросегментация.
- **Q&A №3 (SKILLS)** — см. ВШ №3 (самый важный для понимания сотрудников).
- **Q&A №4** — Упаковка/Оффер: «понятно?»/«хочу?»; рефрейминг в услугу; B2B = «продай деньги» (ROI-калькулятор); воронка через диагностику, не лонгриды.
- **Q&A №5** — Лендинги: GitHub/Vercel-затыки; «продаёт ли лендинг» по смыслам; дизайн-стек; stop-scroll; антиперфекционизм.

### Главные затыки учеников (→ заложить в онбординг Потока 3)
1. Первичная настройка Claude (Git/Homebrew/permissions, Desktop vs Code).
2. Деплой Vercel + GitHub (403, токены).
3. Установка скиллов (локальные vs облачные) — Влад сам признал ошибку.
4. Хаос хранения результатов (нет кросс-памяти) → «всё в одно место».
5. Постановка правильной задачи этапу (язык ЦА — это упаковка, не research).
6. Копирайтинг «видно что AI» → humanizer-ru.
7. FOMO / забегание вперёд → Влад держит группу на текущем этапе.

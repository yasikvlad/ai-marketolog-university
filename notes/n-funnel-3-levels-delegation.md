# 3 уровня делегирования AI — лестница навыков, по которой строится воронка

Воронка устроена вокруг трёх уровней делегирования: **L1 Промптинг** (правильные запросы — все уже умеют, точка входа), **L2 AI-сотрудники** (ассистенты по инструкциям — **сюда бьём**, мало кто умеет), **L3 AI-агенты** (видят цель, сами выбирают инструменты — будущее). L4+ раскрывается на вебе. Глобальный посыл воронки: **«Делегируй рутину ИИ»** (слово «автоматизируй» убрано как менее эмоциональное). Лестница даёт воронке структуру и позволяет показать чёткий «следующий шаг» вместо хаоса возможностей.

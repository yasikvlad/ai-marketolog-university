# 3 флагман-кейса продуктов из голосового — дофаминомика, AI агент автообзвона, гиперперсонализированные медитации

Из голосового Влада, прямая цитата кейсов:
1. **Дофаминомика** — приложение с персонализированным квизом, считает дофамин под каждого человека. Парень (Jedi Monkey, см. seed) использует это в рилсах → набирает подписчиков (2 288 пользователей с $0 рекламы).
2. **AI агент автообзвона** — демонстрирует обзвон клиентов по базе (вероятно, кейс Катерины Дегтярь из seed).
3. **Гиперперсонализированные медитации** — приложение с AI-генерированными медитациями под индивидуальный запрос.

Это **3 рабочих доказательства методологии вайб-кодинга** + интеграции AI с микро-продуктом. Влад использует их как **флагман-доказательства** в продающих коммуникациях. Для маркетологов-преемников: **держите эти 3 кейса в активном продающем арсенале**, переиспользуйте в рилсах, постах, на лендинге.

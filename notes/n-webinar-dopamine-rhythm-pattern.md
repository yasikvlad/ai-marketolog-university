# Влад держит внимание на 3+ часах через цикл «обещание → пауза → подарок» каждые 30-40 минут

В первые 5 минут Влад **анонсирует подарок** через 30-40 минут («поделюсь AI-сотрудниками нажатием одной кнопки»). Это якорь. Пока агенты Claude Code обрабатывают долгие задачи (5-15 мин на этап), Влад заполняет паузу другим контентом: разговором с учеником-кейсом, ответами в Q&A, личной storyline, презентацией программы. Каждые ~30-40 минут даёт «прямо сейчас» доступный подарок: бесплатный скилл, кейс ученика, бонусную инфу. Сам называет это «навешивать дофамин» и говорит, что **конкурирует с TikTok**, где удержание 15s × 100 = такая же длина внимания. Pixel Friends на заднем плане — визуальная метафора «работники работают за меня», даёт ощущение прогресса без необходимости что-то показывать. **Принцип:** аудитория должна получать дофаминовый «пшик» чаще, чем у неё включается «надо закрыть вкладку».

# Философия Влада «2 действия = деньги»

С протокола команды 6 марта 2026:

> **2 ключевых действия, которые приносят деньги:**
> 1. **Говорю** → Сторис / Reels / Telegram (контент)
> 2. **Продаю** → В личке (переписка, обработка лидов)
>
> **Всё остальное — масштабирование и оптимизация** вокруг этих двух действий.

**Это операционная философия проекта**. На её основе формируется:
- Структура команды (Данил → менеджмент контента, Сергей → продажи в личке)
- Приоритеты Влада (контент + личка, не лендинги/SaaS до Sofia)
- Распределение времени (фокус на 2 действия, остальное — авто или делегировать)

**Цитата Влада из протокола:** «Если мы прямо сейчас сегодня решаем задачу менеджмента контента и продаж — у нас будет кэшфлоу каждый день. Пятьсот–тысячу долларов в день.»

**Это работает на уровне:**
- **Самого Влада** (личный operations)
- **Команды** (распределение ролей)
- **Учеников курса** (что им проповедовать)

**Связь с другими нотами:**
- `n-tov-sales-mechanics-30min` — «продаю в личке» в действии
- `n-ai-agent-sells-stratsessions-1500` — AI-агент берёт на себя «продаю в личке»
- `n-funnel-7-stages-webinar` — «говорю» через сторис/рилс есть часть воронки

**Импликация для курса:**
- В программе Потока 2/3 — отдельный блок «2 действия = деньги» как **фундаментальная операционная философия**
- В лендинге — может быть **первый месседж** для предпринимателей (просто, понятно, действенно)
- Для самих маркетологов-преемников: **обоснование, почему фокус Влада** именно на воронке + продаже в личке, а не на лендингах с дизайном

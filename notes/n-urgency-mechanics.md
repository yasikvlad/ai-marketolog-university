# Urgency-стек на лендинге — рост цен через 5 дней + лимиты мест + дата старта + «следующий поток +3 мес»

Лендинг использует **4 одновременных urgency-механики**:
1. **Динамика цен:** через 5 дней $297→$797, $797→$1197, $1197→$2900 (рост ~2× по каждой ступени)
2. **Лимиты мест:** «Участник + Стратегия» — 13 мест (лимит Влада), «Фокус группа» — 6 мест, «Под ключ» — 3 (40–60 часов работы на клиента)
3. **Дата старта:** 18.04.2026 — фиксирован, «живые стримы, подключиться позже нельзя»
4. **Следующий поток через 3 месяца** — «или сейчас, или через 3 мес»

Каждая механика работает **на разной аудитории**: динамика цен — на тех, кто колеблется по цене; лимиты — на статусных/премиум; дата — на тех, кто хочет «сразу»; «следующий поток» — на нерешительных. Стек **умеренно агрессивный** для рынка инфопродуктов, но не доходит до «3, 2, 1 — таймер» уровня. Калибровка по тону Влада — фактологический пресс без истеричности.

# AI-обзвон базы голосом Влада — реактивация 3-6 тыс. лидов за $3 500 себестоимость

На зум-созвоне команды 2026-05-13 Влад представил проект:
- **3-6 тыс. лидов** в старой базе номеров
- AI-агент с **голосом Влада** обзванивает каждого
- Сценарий: «помнишь меня? чем занимаешься? интересно тебе ИИ? бесплатно дам доступ к обучению на 2 недели»
- Себестоимость: **10 центов/минута** × сибирская телефония
- **Полная реализация: ~$3 500**

**Это два продукта одновременно:**
1. **Продукт для самого Влада** — реактивация собственной базы перед запуском Потока 3 (можно конвертировать тёплых в покупателей)
2. **Продукт для продажи студентам / клиентам** — методология AI-обзвона как сервис ($3 500 за реализацию × N клиентов = recurring revenue)

**Маркетинг-возможности:**
- **Кейс для рилсов**: «Уволил колл-центр — AI звонит вместо меня» (уже есть карусель в TG)
- Прозрачные цифры (10¢/мин, 3500$) — **готовый хук**
- Виральный потенциал HIGH (по оценке команды)

**Связь с другими нотами:**
- `n-ai-agent-sells-stratsessions-1500` — AI продаёт стратсессии в переписках
- AI-обзвон + AI-переписка = **полная sales automation pipeline** Влада

**Импликация:**
- Маркетологам-преемникам: использовать этот кейс **в рилсах прогрева Потока 2** (готовая виральность)
- Добавить в roadmap продукта (Поток 3 или отдельный B2B-сервис)
- Связать с n-tech-co-expert (для реализации нужен технарь)

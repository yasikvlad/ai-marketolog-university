# Ценовая сетка $250 / $500 / $800 / $3500 — три рабочих + один якорь сверху

Пакеты AI-Маркетолога: Самостоятельный $250 (записи), Групповой $500 (стримы + Q&A + комьюнити), Групповой + Стратегия $800 (+ личная стратсессия Влада), Под ключ $3500 (Влад делает запуск своими руками). $3500 — **якорь сверху**: делает $800 «дешёвым» (стратсессии от $1500 у конкурентов). Дополнительный якорь — «бюджет запуска бренда $10 000» делает оффер экономией 10×. Якорь по факту почти не продаётся — он нужен только для смещения восприятия основных пакетов.

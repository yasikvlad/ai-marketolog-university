# Воронки Потока 2 раздвоены — холодный канал vs тёплый

Сравнение двух одновременно работающих каналов продаж:

| Параметр | Холодный (лендинг) | Тёплый (TG пост) |
|---|---|---|
| **Канал** | new.aimarketolog.site | Telegram личка / чаты |
| **Оплата** | Прямые WayForPay-кнопки | @yasko_robot (Telegram bot) |
| **Пакеты** | 4 (Куколд + 3 основных) | 3 (без Куколда) |
| **Спецбронь $25** | Есть | Нет |
| **Urgency-механики** | 4 (динамика, лимиты, дата, +3 мес) | Минимальные (даты, лимиты) |
| **Калькулятор потерь** | Есть | Нет |
| **Личная история** | Есть (Hero's Journey) | Нет |
| **FAQ** | Есть (8 вопросов) | Нет |
| **Bonuses prelaunch** | $4200 явных бонусов | «200+ часов моей работы» |
| **Структура программы** | 8 модулей | 7 навыков |

**Тёплый канал = упрощённая версия** для тех, кто уже знаком с Владом. Не нужны:
- Историческая раскачка (они знают)
- Развёрнутый калькулятор потерь (доверие выше)
- Куколд $297 (тёплых не нужно «снижать порог» — они готовы к $647+)

**Импликация:**
- **Сегментация по каналу** — не нужна одна универсальная воронка. Разная глубина для разных аудиторий.
- На холодном лендинге — максимум продающего контента.
- В тёплом Telegram — минимум, ставка на доверие.
- **Метрика конверсии** замеряется раздельно — холодная база может конвертить хуже в %, но абсолют выше из-за охвата.
- Для маркетологов-преемников: **не пытайтесь делать один канал «универсальным»** — это снижает эффект обоих.

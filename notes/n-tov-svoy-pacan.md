# ToV Влада — «свой пацан, взломавший систему», не гуру на пьедестале

Архетип бренда — **парень из окопов**, не гуру. Нарратив: «Был обычным работягой-маркетологом, решил проблему через нейронки, теперь пропускная способность = целый отдел». Четыре характеристики стиля: 1) разговорный «пацанский» (сленг, мат точечно для усиления), 2) прямолинейность без фильтра (не прячет провалы и сырость продукта — **уязвимость = доверие**), 3) энергичность и скорость (короткие импульсные сообщения), 4) антиперфекционизм («криво, но быстро»). Это **очень ниша-зависимый ToV** — работает на маркетологов/предпринимателей, **НЕ работает на психологов и зрелых экспертов** (см. project struchaev-yasko, c-0007).

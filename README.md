# AI-Маркетолог — Университет (база знаний)

Готовая Zettelkasten-база знаний по продукту **AI-Маркетолог** Влада Яско. 136 файлов: первоисточники, атомарные заметки, проверяемые утверждения, синтезы, противоречия, шаблоны.

Это не свалка ссылок — это рабочая база, в которой каждый смысл подкреплён первоисточником и связан с другими через граф.

---

## Как поставить себе (3 варианта)

### Вариант 1. Самый простой — кнопка Download ZIP
1. Нажми зелёную кнопку **`< > Code`** наверху страницы → **Download ZIP**
2. Распакуй архив
3. Переименуй папку в `university/` и положи в свой проект

### Вариант 2. Одной командой в терминал
```bash
curl -L https://github.com/yasikvlad/ai-marketolog-university/archive/refs/heads/main.zip -o university.zip && unzip university.zip && mv ai-marketolog-university-main university && rm university.zip
```

### Вариант 3. Через git (если хочешь обновлять)
```bash
git clone https://github.com/yasikvlad/ai-marketolog-university.git university
```

## Как пользоваться

1. Открой папку проекта в Claude Code: `claude` из директории
2. Кинь Claude новую ссылку/транскрипцию — он положит её в `queue/inbox.md` и прогонит через пайплайн (`METHODOLOGY.md` §4: fetch → classify → score → conspect → atomize → recurse)
3. Спрашивай «что у нас по теме X» — Claude поднимет `syntheses/` + `claims/` и выдаст ответ с цитатами

Подробные правила пайплайна — в [METHODOLOGY.md](METHODOLOGY.md).
Карта тем — в [TAXONOMY.md](TAXONOMY.md).
Все материалы — в [INDEX.md](INDEX.md).

## Структура

| Папка | Что внутри |
|---|---|
| `sources/` | Первоисточники как есть: HTML/PDF/транскрипты. Один источник = одна папка с `meta.yaml` + `conspect.md` |
| `notes/` | Атомарные заметки (Zettelkasten): одна идея = один файл |
| `claims/` | Проверяемые утверждения с доказательствами |
| `syntheses/` | Сводные документы по темам таксономии (до 3000 слов) |
| `contradictions/` | Зафиксированные противоречия между источниками |
| `verdicts/` | Финальные выводы — что работает, что нет |
| `experiments/` | Код + результаты экспериментов для валидации claim'ов |
| `graph/edges.jsonl` | Машиночитаемый граф связей |
| `queue/` | inbox / to-follow / escalation — очереди работ |
| `_templates/` | Шаблоны для новых записей |
